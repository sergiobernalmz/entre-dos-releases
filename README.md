# Entre dos — Releases

Este repositorio publica las versiones de la app **Entre dos** para Android.
Aquí no hay código: solo las releases con el APK listo para instalar.

## Qué es Entre dos

Una app para gestionar el dinero en común de un hogar. Cada miembro aporta
al fondo común en proporción a lo que cobra ese mes, se cubren los gastos
fijos y el sobrante se reparte entre las bolsas de Conjunto, las huchas
personales y el Ahorro común para metas.

## Instalar con Obtainium

1. Instala [Obtainium](https://github.com/ImranR98/Obtainium/releases/latest) en el móvil.
2. En Obtainium, **Add app** y escribe esta dirección:
   `https://github.com/sergiobernalmz/entre-dos-releases`
3. Pulsa **Install**. La app se descarga e instala desde la última release.

No hace falta ninguna cuenta ni token: las releases son públicas.

## Descarga manual

En [Releases](https://github.com/sergiobernalmz/entre-dos-releases/releases)
puedes descargar el archivo `app-release.apk` directamente. Para instalarlo
tendrás que permitir las aplicaciones de origen desconocido en tu móvil.

## Notas

- Cada versión usa el mismo certificado de firma, así que se puede
  actualizar encima de la anterior sin desinstalar.
- El número entre paréntesis de la versión (`versionCode`) solo sube: es
  lo que Android usa para saber si hay una versión más reciente.
